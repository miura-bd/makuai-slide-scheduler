登壇スケジュールを登録すると、時刻に応じて次の登壇者の予告スライドへ自動で切り替わります。

  1. 各スライドを Google スライドで ファイル → 共有 → ウェブに公開
  2. 自動送りの間隔を選び、開始と繰り返しの両方にチェック
  3. 発行された URL を控える
  4. 下のボタンから登壇者と時刻を登録する
設定はこの端末のブラウザに保存されます。複数の端末で使う場合や、設定を残しておきたい場合は、設定画面の「書き出し / 読み込み」から JSON を控えてください。?config=schedule.json のように URL で外部ファイルを指定することもできます。
